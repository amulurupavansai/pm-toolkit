# Prompt library

Ready-to-use prompts for Claude (or any capable assistant). Each file explains how to use the prompt, provides the prompt with `{{placeholders}}`, and shows a filled-in fictional example.

| Prompt | Use it to |
|---|---|
| [Draft a BRD](draft-brd.md) | Turn rough notes into a structured BRD |
| [Generate test cases from requirements](generate-test-cases-from-requirements.md) | Produce traceable positive/negative/boundary cases |
| [Summarise a meeting](summarise-meeting.md) | Extract decisions, actions, risks |
| [Write a status update](write-status-update.md) | Draft an honest RAG status report |

## Good practice
- Remove personal data and confidential details before pasting; use roles instead of names.
- Treat output as a draft. Verify numbers, dates, and regulatory statements.
- Ask the model to list assumptions and open questions so you can validate them.
